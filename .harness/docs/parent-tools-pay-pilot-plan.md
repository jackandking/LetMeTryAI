## 二、试点方向：「测测你是哪种家长类型」

### 2.1 为什么选这个方向

| 理由 | 数据支撑 |
|---|---|
| CTR 最高 | 「家长爱什么」CTR **2.98%**，用户互动意愿最强 |
| 流量基础 | 15,199 曝光/天，足够支撑转化测试 |
| 自然延伸 | 从「投票」→「测试」→「解锁报告」，用户路径顺畅 |
| 低客单价 | ¥1 定价，家长决策成本极低 |

### 2.2 产品流程

```
用户进入「测测你是哪种家长」
    ↓
5 道趣味选择题（免费）
    ↓
显示简略结果：「你是【引导型家长】！」
    ↓
显示「解锁完整分析报告 ¥1.00」
    ↓
点击 → 调起快手支付 → 支付成功
    ↓
展示完整报告：
  ├─ 你的育儿风格深度解析
  ├─ 3 条针对性建议
  ├─ 推荐 2 个家长爱内的相关投票
  └─ 分享海报（带二维码，裂变引流）
```

## 四、技术实现要点

### 4.1 前端：支付调起 + 解锁逻辑

```javascript
// 调起快手支付
ks.pay({
    orderInfo: {
        appId: 'ks703405968097659757',
        prepayId: order.prepayId,
        nonceStr: order.nonceStr,
        timeStamp: order.timeStamp,
        sign: order.sign
    },
    success: (res) => {
        showFullReport(type);
        localStorage.setItem('paid_' + type, '1');
    },
    fail: (err) => {
        alert('支付失败：' + err.errMsg);
    }
});
```

### 4.2 后端：支付接口（部署到 letmetry.cloud）

```javascript
// 预下单
POST https://open.kuaishou.com/openapi/mp/developer/epay/create_order
Body: app_id, access_token, out_order_no, total_amount, subject, notify_url

// 支付回调
POST /api/pay/notify
处理：验签 → 更新订单 → 记录用户已购买
```
