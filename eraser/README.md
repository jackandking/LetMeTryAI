# 爱橡皮 (Love Eraser)

汉字练习助手 - 帮助生成可打印的田字格练习模板

## 功能说明

这个工具允许用户上传包含田字格和汉字的图片，然后生成一个擦除了汉字但保留了拼音和田字格线条的版本，供孩子练习写字使用。

## 技术实现

### 图像处理算法
应用使用纯JavaScript实现的简化图像处理算法：

#### 算法优化 (2025年12月更新)
**简化策略**：直接删除田字格所在的行，而不是复杂的像素分析
1. **横向网格线检测**：识别贯穿图像宽度的横向网格线
2. **拼音区域保护**：保留顶部拼音区域（通常在第一条网格线之前）
3. **整行擦除**：删除网格线之间的所有内容（字符所在行）
4. **网格线保护**：保持网格线本身及其周围像素完整

#### 处理流程
1. **亮度计算**：计算每个像素的亮度值（使用标准公式：0.299R + 0.587G + 0.114B）
2. **检测横向网格线**：找出所有横跨图像的暗色线条
3. **确定拼音区域**：识别第一条网格线之前的区域（通常为顶部30-35%）
4. **整行擦除**：将网格线之间的所有暗色像素替换为白色
5. **保留结构**：保持拼音文本和网格线不被擦除

## 使用说明

1. 打开 `/eraser` 页面
2. 点击或拖拽上传田字格汉字图片
3. 点击"开始处理"
4. 等待客户端处理（通常1-2秒）
5. 下载处理后的图片

**提示**：
- 使用清晰、光线充足的图片效果最佳
- 建议图片中田字格结构规整
- 处理完全在浏览器中进行，无需上传到服务器处理

### 调试模式

如需在移动设备上调试应用，可以启用VConsole：
1. 访问 `/eraser?debug=true`
2. 页面加载后会自动显示VConsole调试面板
3. 可以查看console日志、网络请求、元素信息等

**注意**：正式使用时请勿携带 `debug=true` 参数，以获得最佳性能。
