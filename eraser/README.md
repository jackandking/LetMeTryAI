# 爱橡皮 (Love Eraser)

汉字练习助手 - 帮助生成可打印的田字格练习模板

## 功能说明

这个工具允许用户上传包含田字格和汉字的图片，然后生成一个擦除了汉字但保留了拼音和田字格线条的版本，供孩子练习写字使用。

## 当前实现状态

### ✅ 已完成功能
- 图片上传（支持拖拽和点击上传）
- 文件类型验证（JPG/PNG）
- 文件大小验证（最大10MB）
- 响应式UI设计
- AI集成用于理解用户需求
- 处理流程演示
- 图片下载功能

### 🚧 待完善功能
- **实际图像处理**：当前使用模拟处理，真实环境需要：
  - OCR服务识别汉字和拼音
  - 图像处理算法擦除汉字区域
  - 保留网格线和拼音的精确算法
- **PDF导出**：需要集成jsPDF或类似库
- **批量处理**：支持一次上传多张图片

## 使用说明

1. 打开 `/eraser` 页面
2. 点击或拖拽上传田字格汉字图片
3. 点击"开始处理"
4. 等待AI处理（当前为演示模式）
5. 下载处理后的图片
