# 爱橡皮 (Love Eraser)

汉字练习助手 - 帮助生成可打印的田字格练习模板

## 功能说明

这个工具允许用户上传包含田字格和汉字的图片，然后生成一个擦除了汉字但保留了拼音和田字格线条的版本，供孩子练习写字使用。

## 当前实现状态

### ✅ 已完成功能
- 图片上传（支持拖拽和点击上传）
- 文件类型验证（JPG/PNG）
- 文件大小验证（最大10MB）
- 响应式UI设计
- **客户端图像处理**：使用Canvas API实现
  - 自动检测田字格结构
  - 智能擦除汉字区域
  - 保留拼音和网格线
- 处理后图片下载功能

### 🚧 待完善功能
- **提升处理精度**：当前使用基于启发式的算法，可以改进为：
  - 更精确的网格检测算法
  - 更智能的字符区域识别
  - 机器学习模型辅助（如TensorFlow.js）
- **PDF导出**：集成jsPDF库实现
- **批量处理**：支持一次上传多张图片

## 技术实现

### 依赖
- `util/file-util.js` - 文件上传工具
- `config.js` - 全局配置
- Canvas API - 客户端图像处理

### 图像处理算法
应用使用纯JavaScript实现的图像处理算法：
1. **亮度分析**：计算每个像素的亮度值
2. **网格检测**：自动识别田字格的行列结构
3. **区域划分**：
   - 上部30%保留（拼音区域）
   - 边缘保留（网格线）
   - 中间区域擦除（汉字区域）
4. **智能擦除**：区分细线（网格）和粗线（字符）

## 使用说明

1. 打开 `/eraser` 页面
2. 点击或拖拽上传田字格汉字图片
3. 点击"开始处理"
4. 等待客户端处理（通常1-2秒）
5. 下载处理后的图片

**提示**：
- 使用清晰、光线充足的图片效果最佳
- 建议图片中田字格结构规整
- 处理完全在浏览器中进行，无需上传到服务器处理
