# 人工选题队列

本目录用于存放各品牌的人工提交选题队列。这些文件是**运行时动态数据**，**不纳入 Git 版本控制**。

## 文件说明

| 品牌 | 队列文件 | 说明 |
|------|----------|------|
| 男人宝 | `man-manual-topics.txt` | 男性向娱乐、科技、军事选题 |
| 女人爱 | `woman-manual-topics.txt` | 女性向美妆、时尚、情感选题 |
| 家长爱 | `parent-manual-topics.txt` | 家长向教育、育儿选题 |
| 爱老人 | `elder-manual-topics.txt` | 老年向健康、生活选题 |

## 快速使用

### 添加单个选题
```bash
echo "坦克之王评选" >> topics/man-manual-topics.txt
```

### 批量添加选题
```bash
cat >> topics/man-manual-topics.txt << EOF
战斗机速度对比
最强战舰投票
现代坦克排行
EOF
```

### 查看当前队列
```bash
cat topics/man-manual-topics.txt
```

### 编辑/调整队列
```bash
vi topics/man-manual-topics.txt
```

## 处理机制

1. **优先级**: 只要队列中有选题，就会**完全优先于 AI 选题**处理
2. **顺序**: FIFO（先进先出），按文件中的行顺序处理
3. **清理**: 处理完成的选题会自动从文件顶部删除
4. **回退**: 当队列为空时，自动回退到 AI 生成选题

## 工作流程

```
人工提交 → 进入队列文件 → 下次发布时优先处理 → 完成后自动删除
```

## 注意事项

- 每行一个选题标题，不要留空行
- 文件不存在时系统会自动创建
- 文件为空时自动使用 AI 选题
- 如需插队，直接在文件顶部添加新行
