# 创意提交常见问题 FAQ

## ❓ 提交创意后会发生什么？

### 🎯 简短回答
提交创意后，您的想法会被记录，并显示成功提示。系统正在准备将您的创意自动转化为GitHub Issue，由AI评估并可能开发成实际应用。

### 📋 详细流程

#### 1️⃣ **立即发生**（已实现）
- ✅ 您的创意通过验证检查
- ✅ 表单自动重置
- ✅ 显示成功提示消息
- ✅ 您可以继续提交更多创意

#### 2️⃣ **计划中**（开发中）
- 🔄 创意将自动创建GitHub Issue
- 🔄 Issue标题格式：`[用户创意] 您的标题`
- 🔄 自动指派给AI助手(@copilot)
- 🔄 AI评估创意的可行性
- 🔄 如果可行，自动生成应用代码

## 💡 如何提交创意？

### 方法一：快速输入（推荐简短想法）
1. 在主页顶部的输入框输入您的创意标题
2. 点击"开始创建"按钮
3. 系统会滚动到详细表单并预填标题
4. 补充详细描述后提交

### 方法二：完整表单（推荐详细想法）
1. 滚动到页面底部的"提交您的创意"区域
2. 填写以下信息：
   - **创意标题**（必填，3-100字符）
   - **创意描述**（必填，10-2000字符）
   - **分类**（可选：教育、娱乐、工具、生活、游戏、其他）
3. 点击"🚀 提交创意"按钮

## 📝 提交规范

### 创意标题
- **长度**：3-100个字符
- **建议**：简洁明了，概括核心功能
- **示例**：
  - ✅ "智能诗词生成器"
  - ✅ "每日运动打卡工具"
  - ✅ "AI猜年龄游戏"
  - ❌ "工具"（太短）
  - ❌ "我想要一个..."（不够直接）

### 创意描述
- **长度**：10-2000个字符
- **建议**：详细说明功能、目标用户、使用场景
- **应包含**：
  - 想要解决什么问题？
  - 主要功能是什么？
  - 目标用户是谁？
  - 有什么特色？

### 好的创意描述示例
```
创意：智能诗词生成器

描述：
一个帮助用户创作中国古典诗词的AI工具。

主要功能：
- 用户输入主题或关键词
- AI生成符合格律的诗词（五言、七言、绝句、律诗）
- 提供诗词解释和意境分析
- 支持保存和分享

目标用户：
- 诗词爱好者
- 学生学习古典文学
- 需要创意文案的用户

特色：
- 符合传统格律规范
- 意境优美
- 支持多种诗词体裁
```

## 🎨 创意会被实现吗？

### 评估标准
创意会根据以下标准评估：
- **可行性**：技术上能否实现
- **价值**：对用户是否有用
- **创新性**：是否有独特之处
- **复杂度**：开发工作量是否合理

### 实现优先级
- 🔥 高优先级：创新且实用的小应用
- ⭐ 中优先级：有趣的互动功能
- 💡 低优先级：复杂或小众的功能

### 实现时间
- 简单应用：1-3天
- 中等复杂度：1-2周
- 复杂应用：需要评估

## 🤝 如何提高创意被采纳的机会？

### ✅ 最佳实践
1. **明确具体**：清楚描述功能和使用场景
2. **考虑用户**：说明目标用户和解决的问题
3. **合理范围**：避免过于复杂的需求
4. **参考现有**：可以参考平台上已有的应用
5. **提供细节**：具体的功能点和交互方式

### ❌ 避免这些
1. 描述过于简单或模糊
2. 需求过于复杂或庞大
3. 与现有应用完全重复
4. 技术上不可行的功能
5. 没有实际使用场景
